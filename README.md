# Сжатие видео

Android-приложение для клуба аджилити: пережимает видео тренировок на телефоне
перед отправкой во ВКонтакте или на Яндекс Диск.

- Выбор видео кнопкой или из галереи: «Поделиться → Сжатие видео».
- Качество 720p (≈ 20 МБ на минуту) или 1080p (≈ 40 МБ на минуту).
- Маленькие видео не увеличиваются, битрейт не превышает исходный.
- Результат: «Отправить» (ВК, Яндекс Диск, Telegram…) или «Сохранить в галерею» (Movies/Аджилити).
- Android 7 и новее. Сжатие идёт на аппаратном кодеке телефона (библиотека AndroidX Media3 Transformer).

## Как собрать APK

### Вариант А: GitHub (без установки программ)
1. Создайте бесплатный аккаунт на github.com и новый репозиторий (можно приватный).
2. «Add file → Upload files» — перетащите содержимое этой папки (вместе со скрытой папкой `.github`).
3. Откройте вкладку **Actions** — сборка «Сборка APK» запустится сама (≈ 5 минут).
4. Когда появится зелёная галочка, откройте сборку и скачайте `VideoSzhatie-apk` внизу страницы.
5. Распакуйте zip, перешлите `app-debug.apk` на телефон и установите
   (Android спросит разрешение на установку из этого источника).

### Вариант Б: Android Studio
1. Установите Android Studio, «Open» → эта папка.
2. Дождитесь синхронизации Gradle, затем «Build → Build App Bundle(s) / APK(s) → Build APK(s)».
3. APK окажется в `app/build/outputs/apk/debug/app-debug.apk`.
